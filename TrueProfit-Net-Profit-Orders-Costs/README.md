# TrueProfit — Net Profit, Orders & Costs

بازسازی مستقل و قابل اجرای یک داشبورد **تحلیل سود خالص، سفارش و هزینه‌ها**، الهام‌گرفته از TrueProfit. نویسندهٔ کد و commitها: `kasrapmb`.

**این کد، سورس اصلی TrueProfit نیست.** درخواست به سایت مرجع در این محیط با HTTP 403 روبه‌رو شد. workspace زنده، سورس اصلی یا ظاهر تأییدشدهٔ محصول در اختیار این پروژه نیست. کد، محاسبات و داده‌های نمونهٔ این نسخه مستقل هستند.

## اجرا

Node.js 20.19+ یا 22.12+ و npm لازم است. از همین پوشه:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev -- --host 127.0.0.1 --port 5199
```

برای خروجی production:

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4199
```

برنامه frontend است. هیچ حساب TrueProfit، توکن، فروشگاه واقعی یا backend لازم ندارد.

## قابلیت‌ها

- **Overview:** سود خالص، درآمد، جمع هزینه‌ها، تعداد سفارش، AOV، حاشیهٔ سود و مقایسه با دورهٔ قبلی.
- نمودار روزانهٔ قابل تغییر بین سود، درآمد و هزینه؛ صورت درآمد تا سود با تمام دسته‌های هزینه.
- فیلتر فروشگاه و بازه‌های ۷/۳۰/۶۰روزه یا تاریخ سفارشی؛ نمودار، KPI، هزینه و محصول از همین انتخاب محاسبه می‌شوند.
- **Orders:** جست‌وجو، فیلتر وضعیت، مرتب‌سازی عددی/متنی، صفحه‌بندی و CSV واقعی از تمام ردیف‌های مطابق فیلتر.
- جزئیات سفارش شامل تخفیف، بازپرداخت، ارسال دریافتی، مالیات و تک‌تک هزینه‌ها؛ سفارش زیان‌ده هم مقدار منفی واقعی دارد.
- **Costs:** نمودار توزیع هزینه‌ها و ثبت/حذف هزینهٔ عملیاتی تاریخ‌دار برای یک یا همهٔ فروشگاه‌ها.
- تخصیص هزینهٔ جدید به سفارش‌های واجد شرایط و تغییر فوری سود؛ ذخیره در مرورگر و بازیابی پس از refresh.
- **Products:** رتبه‌بندی محصول بر اساس سود خالص پس از تخصیص تبلیغات و سربار؛ رفتن به سفارش‌های همان محصول.
- جست‌وجو با `Ctrl/Cmd + K`، پنجره‌های native با focus و Escape، طراحی responsive و اسکرول داخلی جدول.

## مدل مالی شفاف

۱۸۰ سفارش ساختگی در ۶۰ روز، از **۳ سپتامبر تا ۱ نوامبر ۲۰۲۶**، تولید می‌شود. نام فروشگاه‌ها و مشتریان نمایشی است؛ هیچ اتصال Shopify یا Amazon وجود ندارد.

```text
Revenue = Gross sales - Discounts - Refunds + Shipping collected
Total costs = COGS + Shipping cost + Payment fees + Fulfillment
            + Advertising + Base operating costs + Added expenses
Net profit = Revenue - Total costs
Net margin = Net profit / Revenue
AOV = Revenue / Order count
Revenue per ad dollar = Revenue / Advertising
```

- مقادیر دفتر محاسباتی **عدد صحیح برحسب سنت** هستند؛ تبدیل به دلار فقط هنگام نمایش و CSV انجام می‌شود.
- هزینهٔ روزانهٔ تبلیغات و سربار، بین سفارش‌های همان روز و فروشگاه تقسیم می‌شود.
- هزینهٔ افزوده‌شده فقط به سفارش‌های **تاریخ و فروشگاه خودش** تخصیص می‌یابد. حالت `All stores` بین تمام سفارش‌های همان روز تقسیم می‌شود؛ سهم فروشگاه‌ها ممکن است برابر نباشد.
- باقی‌ماندهٔ تقسیم سنت‌ها به‌ترتیب ثابت تخصیص می‌یابد؛ جمع تخصیص‌ها دقیقاً برابر هزینهٔ اصلی است.
- هزینه‌های کالا و کارمزد سفارش بازپرداخت‌شده حفظ می‌شوند؛ بازگشت موجودی، برگشت کارمزد یا اعتبار خودکار فرض نشده است.
- مالیات pass-through است و در درآمد و سود وارد نمی‌شود. کارمزد نمونه بر مبنای مبلغ پیش از بازپرداخت محاسبه شده است؛ شبیه‌ساز صورتحساب پردازشگر واقعی نیست.
- مقایسه فقط وقتی نمایش داده می‌شود که دورهٔ قبلیِ هم‌طول به‌طور کامل در دادهٔ نمونه موجود باشد؛ برای دورهٔ ناقص به‌جای درصد ساختگی، خط تیره می‌آید.
- تاریخ‌های نسبی به جدیدترین تاریخ دادهٔ نمونه متصل‌اند، نه ساعت دستگاه.
- جست‌وجو و وضعیت سفارش، فقط جدول و CSV را محدود می‌کنند؛ KPIها همچنان نمای کل فروشگاه/بازهٔ انتخابی هستند.
- در جدول هزینه‌های افزوده‌شده، مبلغ کامل هزینه نمایش داده می‌شود؛ KPI فروشگاه فقط سهم تخصیص‌یافته به همان فروشگاه را نشان می‌دهد.

این مدل یک مطالعهٔ نمایشی است، نه اتصال حسابداری یا گزارش مالی واقعی کسب‌وکار.

## تست مرورگر

ابتدا build کنید. Python 3.10+، Python Playwright و Chromium لازم است:

```sh
python3 -m venv .runtime/test-venv
.runtime/test-venv/bin/pip install -r requirements-test.txt
CHROMIUM_PATH=/usr/bin/chromium .runtime/test-venv/bin/python tests/browser_smoke.py
```

در محیط فعلی `python3 tests/browser_smoke.py` هم قابل اجراست. تست‌ها preview موقت خود را اجرا و متوقف می‌کنند، هر سناریو context مستقل دارد و فایل CSV دانلودشده نیز واقعاً بررسی می‌شود. نتایج در `docs/VALIDATION.md` ثبت شده است.

## مرزهای نسخه

backend، اتصال فروشگاه، همگام‌سازی تبلیغات، همکاری چندکاربره و اطلاعات واقعی وجود ندارد. فقط هزینه‌های افزوده‌شده در `localStorage` همان مرورگر و origin ذخیره می‌شوند؛ تنظیمات فیلتر ذخیره نمی‌شوند و تب‌ها با هم همگام نیستند. دادهٔ سفارش‌ها قابل ویرایش نیست و با کد تولید می‌شود.

اسکیل [reverse-engineer-anything](https://github.com/kasrapmb/REA_skills_Codex/tree/main/REA-Skills/reverse-engineer-anything) برای مرز شواهد و مسیر بازسازی استفاده شد؛ REA MCP متصل نیست و بازیابی سورس اصلی انجام نشده است.

کد مستقل این پروژه MIT است. نام TrueProfit و نام فروشگاه‌ها متعلق به صاحبان خود هستند؛ این پروژه وابسته یا مورد تأیید آن‌ها نیست.
