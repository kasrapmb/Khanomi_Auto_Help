# Anodot — Dashboard, Anomaly Detection & Alert Study

بازسازی مستقل و قابل‌اجرای داشبورد پایش کسب‌وکار، کشف ناهنجاری، مدیریت هشدار و بررسی سیگنال‌های مرتبط.

**این پروژه سورس اصلی یا کلون تأییدشدهٔ محصول Anodot نیست.** سایت اصلی در محیط بررسی با خطای `CONNECT tunnel failed, response 403` از پراکسی شبکه مسدود شد. رابط محصول واردشده، APIها، الگوریتم‌ها و سورس خصوصی آن مشاهده نشده‌اند. ظاهر، معماری و داده‌های این پروژه طراحی مستقل‌اند. هیچ ادعایی دربارهٔ پشتهٔ فنی واقعی Anodot نداریم.

## اجرا

بدون وابستگی npm، بدون حساب کاربری و بدون کلید API. Python 3.10+ برای سرور و Node.js 20+ برای تست محاسبات کافی است:

```sh
cd Anodot-Dashboard
npm run dev
```

سرور داخلی روی پورت 5220 اجرا می‌شود. فایل `index.html` باید از سرور ارائه شود، چون از ماژول‌های JavaScript استفاده می‌کند. مرحلهٔ build لازم نیست؛ همین فایل‌ها قابل انتشار به‌صورت static هستند.

## قابلیت‌ها

- داشبورد تیره و responsive، کارت‌های KPI و نمودارهای SVG برای درآمد، نرخ تبدیل و تأخیر API
- شش سری زمانی مصنوعی با ۷۲ نمونهٔ ۲۰ دقیقه‌ای، پنج رخداد هم‌زمان و یک رخداد مستقل
- کشف ناهنجاری بر اساس میانگین و انحراف معیار ۲۴ نمونهٔ **قبلی**؛ بدون استفاده از نمونهٔ جاری یا دادهٔ آینده در خط مبنا
- نمودار خط مبنا و محدودهٔ آماری متحرک، نمایش زمان، مقدار مشاهده‌شده، مقدار مورد انتظار و درصد انحراف
- رتبه‌بندی ناهنجاری‌ها بر اساس امتیاز انحراف؛ جست‌وجوی شاخص/segment و فیلتر شدت
- پنجرهٔ بررسی با سیگنال‌های دارای شروع نزدیک، اختلاف زمانی و چک‌لیست بررسی
- وضعیت‌های Open، Acknowledged، Snoozed و Resolved با ذخیره در localStorage
- حساسیت قابل تنظیم و بازنشانی تنظیمات؛ خروجی CSV مطابق فیلتر جاری
- مدیریت دادهٔ ذخیره‌شدهٔ خراب، خطای ذخیره‌سازی، Escape، focus مرورگر و نمایش موبایل

هم‌زمانی، اثبات علت نیست. این نسخه موتور تحلیل علّی، مدل یادگیری ماشین، seasonal baseline، backend، ingestion واقعی، ارسال ایمیل/Slack و اتصال Anodot ندارد. Snoozed تا بازکردن دستی خاموش می‌ماند. مقادیر جاری ممکن است به حالت عادی برگشته باشند، ولی رخداد تا بررسی کاربر در فهرست می‌ماند. محدودهٔ نمودار برای جاگرفتن در محور عمودی بریده می‌شود.

## تست

```sh
npm test
python3 -m venv .runtime/test-venv
.runtime/test-venv/bin/pip install -r requirements-test.txt
CHROMIUM_PATH=/usr/bin/chromium .runtime/test-venv/bin/python tests/browser_smoke.py
```

در محیط فعلی Playwright در `/workspace/linear-test-venv` از قبل نصب شده است. تست مرورگر سرور موقت خودش را اجرا و متوقف می‌کند و فقط از contextهای موقت با دادهٔ مصنوعی استفاده می‌کند. نتیجهٔ واقعی: **۷ تست محاسباتی و ۵ تست مرورگر پاس شدند**. هیچ تستی علیه محصول اصلی اجرا نشده است.

## سورس و شواهد

- `src/engine.js`: دادهٔ نمونه، خط مبنا، تشخیص، گروه‌بندی زمانی و CSV
- `src/app.js`: نماها، نمودار، فیلترها، مدیریت هشدار و persistence
- `src/style.css`: رابط responsive بدون فونت، CDN یا asset خارجی
- `tests/`: تست‌های محاسباتی و تعاملی
- [گزارش بررسی](docs/INVESTIGATION.md): مرز مشاهده، طراحی و مجهولات
- [تصویر دسکتاپ](docs/desktop.png)، [بررسی رخداد](docs/investigation.png)، [موبایل](docs/mobile.png): تصاویر همین پیاده‌سازی محلی

اسکیل استفاده‌شده: [reverse-engineer-anything](https://github.com/kasrapmb/REA_skills_Codex/tree/main/REA-Skills/reverse-engineer-anything). دستورالعمل اسکیل خوانده و diagnostic واقعی CLI اجرا شد؛ ابزار MCP متصل نبود و نسخهٔ Node موجود شرط CLI را برآورده نمی‌کرد. هیچ REA Evidence از محصول اصلی یا decompilation ادعا نمی‌شود.

کد مستقل تحت MIT ارائه می‌شود. نام Anodot متعلق به صاحب آن است؛ این نمونه وابسته یا مورد تأیید آن نیست.
