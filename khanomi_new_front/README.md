# Khanomi Intelligence — بازسازی رابط کاربری

بازسازی مستقل داشبورد فارسی بر اساس تصویر مرجع؛ Vite، JavaScript و CSS با فونت محلی Vazirmatn و آیکون‌های Lucide. داده‌ها نمونه‌اند؛ اتصال به API یا هوش مصنوعی پیاده‌سازی نشده است. نشان و موج‌ها با SVG بازطراحی شده‌اند و دارایی اصلی تصویر نیستند.

## اجرا

```bash
cd /workspace/Khanomi_Auto_Help/khanomi_new_front
npm ci
npm run dev -- --port 5173
```

## بررسی

```bash
npm run build
# With the development server running, and Chromium available:
node scripts/smoke.mjs
```

تصاویر بررسی مرورگر در `artifacts/desktop.png` و `artifacts/mobile.png` تولید می‌شوند. آزمون، تغییر بازه، جستجو، پنجره‌ها، خطاهای مرورگر و عرض‌های ۳۹۰، ۷۶۸ و ۱۲۸۰ را بررسی می‌کند.

## رفتارها

انتخاب بازه نمودار و درصد عملکرد را تغییر می‌دهد. Enter در جستجو پنجره نتیجه نمایشی را باز می‌کند. میانبر Ctrl/Cmd+K جستجو را فعال می‌کند. منو و ابزارها پنجره جزئیات نمایشی دارند؛ Escape آن‌ها را می‌بندد.

## مبنای بازسازی

اسکیل REA از https://github.com/kasrapmb/REA_skills_Codex خوانده شد. مرجع فقط تصویر است؛ کد، سرویس‌ها و تعاملات اصلی نامشخص‌اند. ابزار MCP مربوط به REA در نشست ثبت نشده بود (doctor: registration missing). هیچ تحلیل کد اصلی یا رفتار زنده ادعا نمی‌شود. برای اجرای این پروژه، REA لازم نیست.

از checkout موجود استفاده کنید؛ محیط cloud ایزوله است و بدون درخواست صریح کاربر نیازی به worktree جدید نیست. فرایند dev باید در نشست جدید دوباره راه‌اندازی شود.

## جلوه‌های تعاملی

هالهٔ موس روی کارت‌ها، حاشیهٔ نورانی، بازخورد هاور و کلیک، حرکت ملایم پس‌زمینه، ورود کارت‌ها و نمودارها اضافه شده است. دکمهٔ ستاره در نوار بالا حرکت را روشن/خاموش می‌کند. تنظیم کاهش حرکت سیستم اولویت دارد و تعامل لمسی به هاور وابسته نیست.

```bash
node scripts/effects-smoke.mjs
```

جزئیات بررسی REA و محدودیت دسترسی به سایت مرجع در [یادداشت تعاملات](docs/interaction-notes.md) ثبت شده است.
