# Linear — Issue Management & UX Study

بازسازی مستقل و قابل اجرای یک فضای کاری **الهام‌گرفته از Linear** برای مطالعهٔ مدیریت پرونده‌ها و تجربهٔ کاربری. این پروژه به نام `kasrapmb` نوشته شده است.

**این پوشه سورس اصلی Linear نیست.** درخواست به `https://linear.app/` در این محیط با HTTP 403 روبه‌رو شد؛ ظاهر و رفتار محصول آنلاین ضبط یا با این نسخه مقایسه نشده است. سورس این پیاده‌سازی کاملاً در همین پوشه قرار دارد و وابسته به حساب Linear نیست.

## اجرا

پیش‌نیاز: Node.js 20.19+ یا 22.12+ و npm. از همین پوشه:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev -- --host 127.0.0.1 --port 5177
```

برای خروجی production:

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4177
```

این برنامه فقط frontend است؛ سرور Vite برای ارائهٔ فایل‌هاست. اطلاعات در `localStorage` همان مرورگر و origin ذخیره می‌شوند، بنابراین تغییر پورت یا مرورگر، فضای دادهٔ جداگانه‌ای دارد.

## چه چیزهایی واقعاً کار می‌کنند؟

- نمایش پرونده‌ها در **فهرست گروه‌بندی‌شده** و **برد**؛ جابه‌جایی کارت با drag & drop در دسکتاپ
- ساخت، ویرایش و حذف پرونده با شناسهٔ خودکار؛ تأیید پیش از حذف
- تغییر وضعیت، اولویت، مسئول، پروژه و تاریخ سررسید
- انتخاب label هنگام ساخت پرونده؛ ثبت نظر و تاریخچهٔ تغییر خصوصیات
- جست‌وجو بر اساس عنوان، شناسه، توضیح و label؛ فیلتر وضعیت و اولویت؛ مرتب‌سازی
- پروژه‌ها با پیشرفت محاسبه‌شده از داده‌ها، پرونده‌های من و علاقه‌مندی‌ها
- Inbox برای نظرهای ثبت‌شده در همین فضای محلی
- جست‌وجوی سریع با `Ctrl/Cmd + K`، ساخت با `C` و بستن پنجره با `Esc`
- پنجره‌های modal با مدیریت focus مرورگر، طراحی responsive و منوی موبایل
- ذخیرهٔ خودکار، بازیابی پس از refresh و بازگشت به دادهٔ اولیه در صورت خرابی cache

۱۶ پروندهٔ اولیه و نام‌های تیم، دادهٔ نمایشی هستند. حساب فعال داخل نمونه «Kasra» است؛ نویسندهٔ Git با نام `kasrapmb` ثبت می‌شود.

## تست واقعی در مرورگر

پس از build، با Python 3.10+:

```sh
python3 -m venv .runtime/test-venv
.runtime/test-venv/bin/pip install -r requirements-test.txt
CHROMIUM_PATH=/usr/bin/chromium .runtime/test-venv/bin/python tests/browser_smoke.py
```

Chromium باید نصب باشد؛ مسیر اجرایی را با `CHROMIUM_PATH` تعیین کنید. تست‌ها یک سرور preview موقت اجرا و سپس متوقف می‌کنند؛ اطلاعات تست فقط داخل contextهای موقت مرورگر ذخیره می‌شود. در محیط آمادهٔ این پروژه، `python3 tests/browser_smoke.py` نیز قابل اجراست.

## مرزهای این نسخه

این نمونه، backend، ورود کاربران، همگام‌سازی تیمی، API گراف‌کیوال Linear، اتصال سرویس‌های بیرونی، اعلان زنده یا همکاری هم‌زمان ندارد. Inbox از نظرهای محلی ساخته می‌شود. داده‌ها با پاک‌شدن storage مرورگر از دست می‌روند. drag & drop برای دسکتاپ است؛ در موبایل وضعیت را از پنجرهٔ جزئیات تغییر دهید.

اسکیل [reverse-engineer-anything](https://github.com/kasrapmb/REA_skills_Codex/tree/main/REA-Skills/reverse-engineer-anything) برای تعیین مسیر بررسی و تفکیک مشاهده از بازسازی استفاده شد. MCP مربوط به REA متصل نیست و ضبط یا بازیابی سورس اصلی انجام نشده است.

کد مستقل این پروژه تحت مجوز MIT است؛ نام و علائم Linear متعلق به صاحبان خود هستند. این پروژه وابسته یا مورد تأیید Linear نیست.
