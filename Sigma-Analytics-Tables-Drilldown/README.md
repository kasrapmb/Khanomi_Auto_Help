# Sigma — Analytics Tables & Drilldown

یک بازسازی مستقل و قابل اجرا از تجربهٔ **جدول تحلیلی و بررسی جزئیات داده**، الهام‌گرفته از Sigma. نویسندهٔ کد و commitها: `kasrapmb`.

**این پوشه سورس اصلی Sigma نیست.** دسترسی به سایت مرجع در این محیط HTTP 403 برگرداند؛ هیچ workspace واقعی، سورس اصلی یا تصویر زنده‌ای از محصول ضبط نشده است. تمام کدِ این پیاده‌سازی مستقل در همین پوشه قرار دارد.

## اجرا

پیش‌نیاز: Node.js 20.19+ یا 22.12+ و npm. از همین پوشه:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev -- --host 127.0.0.1 --port 5188
```

خروجی production:

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4188
```

برنامه frontend است؛ Vite فقط فایل‌ها را ارائه می‌کند. حساب Sigma، API key، دیتابیس و اتصال warehouse لازم نیست.

## قابلیت‌های پیاده‌سازی‌شده

- **Sales overview:** درآمد، سود ناخالص، تعداد سفارش و میانگین مبلغ سفارش؛ همگی از ردیف‌های فیلترشده محاسبه می‌شوند.
- نمودار ماهانه و نمودار منطقه‌ای؛ کلیک روی منطقه، جدول و معیارها را فیلتر می‌کند.
- **Order explorer:** جست‌وجوی سفارش، مشتری و محصول؛ فیلتر منطقه، دسته، وضعیت و بازهٔ زمانی.
- مرتب‌سازی متنی و عددی، صفحه‌بندی و انتخاب تعداد ردیف در صفحه.
- گروه‌بندی بر اساس منطقه، دسته، وضعیت یا مشتری؛ بازکردن گروه برای دیدن ردیف‌های منبع و جمع هر گروه.
- نمایش/پنهان‌کردن ستون‌ها؛ امکان بازکردن جزئیات حتی با پنهان‌کردن ستون شناسه.
- انتخاب ردیف‌ها، جمع درآمد انتخاب‌ها و **CSV واقعی** از همهٔ ردیف‌های فیلترشده یا فقط انتخاب‌ها، با ستون‌های قابل نمایش.
- جزئیات سفارش با کالا، تعداد، قیمت واحد، تخفیف، هزینه، سود و مشتری؛ رفتن به همهٔ سفارش‌های همان مشتری.
- **Explore data:** انتخاب بُعد گروه‌بندی و معیار برای خلاصهٔ تعاملی؛ کلیک روی نتیجه، ردیف‌های منبع را نشان می‌دهد.
- ذخیرهٔ یک نمای نام‌گذاری‌شده شامل فیلتر، ترتیب و ستون‌ها؛ بازیابی پس از refresh.
- جست‌وجو با `Ctrl/Cmd + K`، پنجرهٔ native با focus و Escape، منوی موبایل و اسکرول افقی داخل جدول.

## تعریف داده و محاسبات

۲۴۰ سفارش ساختگی و تکرارپذیر در `src/data.js` تولید می‌شوند. نام مشتریان، صاحبان حساب و محصولات نمایشی است.

- درآمد سفارش = مبلغ ناخالص پس از تخفیف.
- سود ناخالص = درآمد − هزینه.
- حاشیهٔ سود کل = جمع سود ÷ جمع درآمد؛ میانگین سادهٔ حاشیهٔ ردیف‌ها نیست.
- میانگین مبلغ سفارش = جمع درآمد ÷ تعداد سفارش‌ها.
- به‌طور پیش‌فرض همهٔ وضعیت‌ها، از جمله `Refunded`، در جمع مبلغ ثبت‌شدهٔ سفارش‌ها حضور دارند. برای درآمد سفارش‌های تکمیل‌شده، وضعیت را روی `Completed` بگذارید. این مدل، دفتر حسابداری یا محاسبهٔ درآمد خالص پس از استرداد نیست.
- تاریخ‌های نمونه از مه تا نوامبر ۲۰۲۶ هستند؛ «۳۰/۹۰ روز اخیر» نسبت به جدیدترین تاریخ همین دادهٔ نمونه محاسبه می‌شود.
- انتخاب‌ها هنگام تغییر فیلتر پاک می‌شوند؛ خروجی CSV محدود به صفحهٔ جاری نیست.
- دادهٔ سفارش‌ها immutable است. فقط یک نمای تنظیمات در storage همان مرورگر/origin ذخیره می‌شود؛ بین دستگاه‌ها یا کاربران مشترک نیست.

## تست مرورگر

ابتدا build کنید. با Python 3.10+، Python Playwright و Chromium:

```sh
python3 -m venv .runtime/test-venv
.runtime/test-venv/bin/pip install -r requirements-test.txt
CHROMIUM_PATH=/usr/bin/chromium .runtime/test-venv/bin/python tests/browser_smoke.py
```

تست‌ها سرور preview موقت خود را اجرا و متوقف می‌کنند و contextهای مرورگر جداگانه دارند. در محیط فعلی، `python3 tests/browser_smoke.py` نیز قابل اجراست. جزئیات نتایج در [VALIDATION.md](docs/VALIDATION.md) ثبت می‌شود.

## محدودیت‌ها

این نسخه backend، همکاری هم‌زمان، ورود کاربران، اتصال به Sigma، warehouse، SQL یا به‌روزرسانی دادهٔ زنده ندارد. Explore یک گروه‌بندی محلی واقعی روی دادهٔ نمونه است؛ SQL یا AI جعلی نمایش نمی‌دهد. تصاویر متعلق به همین پیاده‌سازی محلی‌اند و تطابق تصویری با محصول اصلی تأیید نشده است.

اسکیل [reverse-engineer-anything](https://github.com/kasrapmb/REA_skills_Codex/tree/main/REA-Skills/reverse-engineer-anything) برای مسیر بررسی و مرز شواهد استفاده شد؛ REA MCP متصل نیست و ادعای خروجی مهندسی معکوس یا بازیابی سورس اصلی وجود ندارد.

مجوز کد مستقل این پروژه MIT است. نام Sigma متعلق به صاحب آن است؛ این نمونه وابسته یا مورد تأیید Sigma نیست.
